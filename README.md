# HH Goa 2026 — Builder ID & PFP Frame Generator

> **#FrameInGoa** — Turn your builder identity into a branded event badge or profile picture ready for X (Twitter).

Built for the **Hacker House Goa 2026** shortlisting task.

---

## ✨ Features

- 🎴 **Format B: Builder ID Card**: 4:5 ratio event badge featuring photo, name, stack/role, currently building status, and a passport-style rotated stamped builder title (`THE RAPID ARCHITECT`, `THE NEURAL ALCHEMIST`, etc.).
- 🖼️ **Format A: PFP Frame / Overlay**: 1:1 square profile picture frame wrapping the user's photo with HH Goa branding, ideal for X profile pictures.
- 📱 **iPhone HEIC Photo Support**: Native client-side conversion for iPhone `.heic`/`.heif` photo uploads.
- 🎨 **Photo Style Filters**: Switch between Original Color, Signature Teal Duotone, Mono B&W, and Retro Warm Poster Tint.
- 🎲 **Interactive Title Shuffler**: Refresh generated builder titles dynamically.
- 📤 **Sharing & Exporting**: Native Web Share API (direct image sharing on mobile) + Copy Image to Clipboard + Pre-filled caption with `#FrameInGoa` hashtag.
- ⚡ **Zero Backend / Instant Execution**: Fully client-side HTML5 Canvas rendering — fast, private, no signup required.

## 🚀 Getting Started

Simply open `index.html` in any web browser, or serve locally with Python:

```bash
python -m http.server 8080
```

Open `http://localhost:8080` to run the generator.
